# Mel e Minie Tutor PC Overlay V4

Esta é a versão mais rígida da especificação para o Codex.

O objetivo é reduzir ao máximo margem para erro, obrigando o Codex a seguir um contrato técnico, pedagógico e visual antes de considerar o app pronto.

## O que mudou na V4

1. Mel e Minie estão definidas sem ambiguidade como duas cachorrinhas yorkshire.
2. O tutorial agora ensina a própria usuária a abrir, pausar, retomar, repetir e fechar o tutorial.
3. O app passa a ter um contrato de entrega com critérios obrigatórios.
4. O Codex deve fazer autoverificação antes de entregar.
5. O avanço nas aulas depende de fixação de conteúdo.
6. O overlay deve trabalhar sobre programas reais no Windows 11.
7. O app deve funcionar com duas telas.
8. O instalador deve ser único para Windows.
9. A interface deve passar em testes contra sobreposição.
10. Nenhum TODO, placeholder, componente fake ou função vazia pode ficar no projeto final.

Um instalador único para Windows 11
