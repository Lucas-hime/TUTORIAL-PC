# Módulo ChatGPT

## Objetivo

Ensinar a usar o ChatGPT como ferramenta de ajuda no dia a dia.

## Princípio

ChatGPT não deve ser apresentado como autoridade absoluta.

Deve ser apresentado como assistente que ajuda a explicar, organizar, reescrever e dar passos.

## Aulas

### Aula 1

Abrir ChatGPT

Ensinar

1. Abrir navegador.
2. Clicar na barra de endereço.
3. Digitar chatgpt.com.
4. Esperar carregar.

Validação

Janela do navegador ativa e pergunta de fixação

Onde digitamos o endereço do site?

### Aula 2

Campo de mensagem

Ensinar

1. Onde escrever.
2. Como enviar.
3. O que é uma conversa.

Teste

Clique na região onde se escreve a mensagem.

### Aula 3

Primeira pergunta

Prompt de treino

Explique passo a passo como criar uma pasta no Windows 11.

Validação

Usuária envia mensagem e responde o que apareceu

1. Uma resposta.
2. Um erro.
3. Uma tela de senha.

### Aula 4

Pedir explicação simples

Prompt de treino

Explique de um jeito mais simples.

Fixação

Quando a resposta ficou difícil, o que você pode pedir?

### Aula 5

Pedir passo a passo

Prompt de treino

Me dê os passos em ordem, um por vez.

Fixação

Por que pedir passo a passo ajuda?

### Aula 6

Pedir exemplo

Prompt de treino

Me dê um exemplo.

### Aula 7

Reescrever texto

Prompt de treino

Reescreva este texto de forma mais clara.

### Aula 8

Ajuda com Word

Prompt de treino

Estou no Word e quero aumentar a letra. Me explique devagar.

### Aula 9

Novo chat

Ensinar

1. O que é novo chat.
2. Quando usar.
3. Cuidado para não perder conversa se não estiver logada.

### Aula 10

Segurança

Ensinar a não compartilhar

1. Senhas.
2. Dados bancários.
3. Código de verificação.
4. Documentos pessoais sem necessidade.
5. Informações íntimas.

### Aula 11

Conferir resposta

Ensinar

1. ChatGPT pode errar.
2. Para dados importantes, confirmar.
3. Pedir fontes quando for assunto sério.
4. Perguntar novamente se ficou estranho.

### Aula 12

Prompt bom

Estrutura simples

Quero fazer X.

Estou usando Y.

Me explique passo a passo.

Use palavras simples.

Exemplo

Quero salvar um documento no Word. Estou no Windows 11. Me explique passo a passo, usando palavras simples.

## Teste final do módulo

A usuária deve

1. Abrir ChatGPT.
2. Enviar um prompt pedindo ajuda para usar o Word.
3. Pedir explicação mais simples.
4. Pedir passos numerados.
5. Identificar uma informação que não deve compartilhar.
