# Tutorial para abrir, pausar, retomar e fechar o próprio tutorial

Este módulo é obrigatório e deve ser o primeiro no app.

## Nome do módulo

Conhecendo a Mel e a Minie

## Objetivo

Ensinar a usuária a controlar o próprio tutorial antes de aprender outros programas.

## Aula 1

Abrir o tutorial

Ensinar

1. O atalho fica na área de trabalho.
2. O nome do atalho é Mel e Minie Tutor PC.
3. Para abrir, clicar duas vezes no atalho.
4. Se não abrir, tentar pelo menu iniciar.

Demonstração visual

1. Destacar o atalho.
2. Ponteiro guia mostra o duplo clique.
3. Mel explica.
4. Minie diz que duplo clique são dois cliques rápidos.

Teste de fixação

Pergunta

Onde você clica para abrir o tutorial?

Resposta esperada

No atalho Mel e Minie Tutor PC.

## Aula 2

Entender o overlay

Ensinar

1. A Mel aparece por cima da tela.
2. Isso não significa que o programa fechou.
3. O tutorial fica acompanhando.
4. Ela pode clicar no programa real normalmente.

Demonstração visual

1. Mel corre para o canto seguro.
2. Overlay destaca uma área.
3. Mostrar que o clique passa para o programa real.

Teste

A usuária deve identificar o que é tutorial e o que é programa real.

## Aula 3

Pausar o tutorial

Ensinar

1. O botão Pausar deixa o tutorial quieto.
2. O programa real continua aberto.
3. Pausar não apaga progresso.

Demonstração visual

1. Destacar botão Pausar.
2. Ponteiro guia mostra o botão.
3. Mel explica.
4. Usuária clica em Pausar.

Validação

Overlay muda para modo recolhido.

## Aula 4

Retomar o tutorial

Ensinar

1. O botão flutuante retoma a aula.
2. Retomar volta ao mesmo passo.

Demonstração visual

1. Destacar botão flutuante.
2. Usuária clica em Retomar.

Validação

Aula volta ao passo anterior.

## Aula 5

Repetir demonstração

Ensinar

1. O botão Repetir demonstração mostra de novo.
2. Repetir não é erro.
3. Pode repetir quantas vezes quiser.

Teste

Usuária deve repetir a demonstração uma vez.

## Aula 6

Estou perdida

Ensinar

1. Usar quando não souber onde está.
2. O app mostra a janela certa.
3. O app destaca a barra inferior.
4. O app pode trazer o painel de volta.

Teste

Usuária clica em Estou perdida e escolhe Voltar para esta etapa.

## Aula 7

Fechar tutorial com segurança

Ensinar

1. Fechar tutorial não apaga o progresso.
2. Não fecha Word ou PowerPoint automaticamente.
3. Ao abrir de novo, pode continuar.

Demonstração visual

1. Destacar botão Fechar tutorial.
2. Mel explica que o progresso será salvo.
3. Confirmar fechamento.

Validação

App salva progresso e fecha overlay.

## Aula 8

Abrir de novo e continuar

Ensinar

1. Abrir pelo atalho.
2. Clicar em Continuar de onde parei.
3. Ver a aula anterior salva.

Validação

Progresso recuperado.

## Gate do módulo

A próxima área do app só libera se a usuária demonstrar

1. Sabe pausar.
2. Sabe retomar.
3. Sabe repetir demonstração.
4. Sabe usar Estou perdida.
5. Sabe fechar.
6. Sabe abrir novamente.

## Frases da Mel

Eu vou ficar por cima da tela para te mostrar onde olhar.

Se quiser parar um pouco, use Pausar.

Se quiser sair, use Fechar tutorial. Seu progresso fica salvo.

Se você se perder, clique em Estou perdida.

## Frases da Minie

Pausar não apaga nada.

Repetir é normal.

O atalho fica na área de trabalho.

Se sumiu, procure na barra inferior.
