# Currículo em ordem lógica para Windows 11

## Ordem obrigatória

1. Janelas, duas telas e orientação no Windows 11.
2. Explorador de Arquivos.
3. Word.
4. PowerPoint.
5. Internet.
6. ChatGPT.
7. Rotina de organização.
8. Revisões.

## Módulo 1

Janelas e duas telas no Windows 11

Objetivo

Ensinar como não se perder quando várias coisas estão abertas.

Aulas

1. Entender área de trabalho.
2. Entender barra inferior.
3. Abrir e fechar uma janela.
4. Minimizar.
5. Recuperar janela minimizada.
6. Maximizar.
7. Restaurar janela.
8. Arrastar janela pela barra de título.
9. Mover janela para a segunda tela.
10. Trazer janela de volta para a tela principal.
11. Usar Snap arrastando para a lateral.
12. Usar Snap com duas janelas lado a lado.
13. Usar Alt Tab para trocar de janela.
14. Entender quando o tutor está em uma tela e o programa em outra.
15. Usar Estou perdida.

Teste do módulo

A usuária deve mover uma janela para a segunda tela, minimizar, recuperar e colocar lado a lado com outra janela.
