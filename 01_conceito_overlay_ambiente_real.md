# Conceito do overlay em ambiente real

## Mudança de conceito

O app não é um curso separado.

O app é uma professora sobreposta à tela real.

A mãe aprende usando o próprio Windows 11, o Explorador de Arquivos, Word, PowerPoint, navegador e ChatGPT.

## Como a aula começa

1. A usuária abre o app.
2. Escolhe uma aula.
3. O app abre o programa real necessário.
4. A Mel aparece correndo até o canto da tela.
5. A Mel explica a interface.
6. A Minie mostra uma dica curta.
7. O overlay destaca onde olhar ou clicar.
8. A usuária faz a ação.
9. O app verifica.
10. O app aplica teste de fixação.
11. Só então libera a próxima etapa.

## O que significa mostrar

Mostrar não é só escrever.

O app deve usar

1. Ponteiro guia.
2. Destaque piscante.
3. Seta.
4. Máscara escurecida com área clara.
5. Balão de explicação.
6. Animação curta da Mel.
7. Dica curta da Minie.

## Exemplo no Word

Objetivo

Aumentar o tamanho do texto.

Fluxo

1. Abrir Word.
2. Pedir para digitar uma frase.
3. Pedir para selecionar a frase.
4. Destacar a parte superior do Word onde fica a fonte.
5. Ponteiro guia se move até o controle de tamanho da fonte.
6. Mel explica que tamanho da fonte muda o tamanho das letras.
7. Minie diz que números maiores deixam a letra maior.
8. A usuária aumenta o tamanho.
9. O app pergunta qual botão muda tamanho da fonte.
10. A usuária precisa acertar para avançar.

## Exemplo no Explorador de Arquivos

Objetivo

Criar uma pasta.

Fluxo

1. Abrir pasta de treino.
2. Piscar uma área vazia.
3. Mel explica que precisa clicar em espaço vazio.
4. Ponteiro guia mostra botão direito.
5. Minie lembra que botão direito mostra opções.
6. A usuária cria a pasta.
7. O app verifica se a pasta existe.
8. O app pede para repetir com outro nome.
9. Só avança depois da segunda pasta criada.

## Exemplo no PowerPoint

Objetivo

Criar novo slide.

Fluxo

1. Abrir PowerPoint.
2. Destacar botão Novo Slide.
3. Ponteiro guia mostra onde clicar.
4. Mel explica o que é slide.
5. Minie diz que slide é uma página da apresentação.
6. A usuária cria o slide.
7. Teste pergunta onde fica o botão Novo Slide.
8. A usuária clica na área correta indicada no overlay.

## Exemplo na internet

Objetivo

Entrar no ChatGPT.

Fluxo

1. Abrir navegador.
2. Destacar barra de endereço.
3. Mel explica que barra de endereço é onde se digita site.
4. Minie avisa para não confundir com campo de pesquisa.
5. A usuária digita chatgpt.com.
6. O app ensina novo chat, campo de mensagem e envio.
7. A usuária manda um prompt simples.
8. O app aplica teste de fixação.

## Botões sempre disponíveis

1. Fechar tutorial.
2. Pausar.
3. Repetir demonstração.
4. Estou perdida.
5. Chamar Minie.
6. Voltar para etapa anterior.

## Botão Estou perdida

Quando a usuária clicar

1. O app pausa a aula.
2. Mel explica onde está.
3. O overlay destaca a barra inferior.
4. O app mostra qual janela deve estar ativa.
5. O app oferece botão Trazer tutorial para cá.
6. O app oferece botão Recomeçar esta etapa.

## Fechar tutorial

A usuária pode fechar o tutorial a qualquer momento.

Ao fechar

1. Salvar progresso.
2. Não fechar Word ou PowerPoint automaticamente.
3. Mostrar mensagem curta.
4. Permitir retomar depois.

## Pausar

Ao pausar

1. O overlay reduz para um botão flutuante.
2. Mel fica recolhida.
3. Nenhum destaque fica piscando.
4. A usuária pode continuar usando o computador.
5. Clicar no botão flutuante retoma a aula.

## Módulo zero obrigatório

Antes de qualquer aula de Windows, o app deve ensinar a usuária a controlar o próprio tutorial.

Esse módulo chama Conhecendo a Mel e a Minie.

Ele ensina

1. Abrir o app pelo atalho.
2. Entender que Mel e Minie são duas cachorrinhas yorkshire que aparecem por cima da tela.
3. Pausar.
4. Retomar.
5. Repetir demonstração.
6. Usar Estou perdida.
7. Fechar tutorial.
8. Abrir novamente e continuar.

Esse módulo bloqueia o restante até a usuária passar no gate de controle do tutorial.
