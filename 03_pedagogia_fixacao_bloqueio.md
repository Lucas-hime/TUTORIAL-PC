# Pedagogia com fixação e bloqueio de avanço

## Regra central

A usuária só avança quando demonstra que fixou.

Não basta assistir.

Não basta clicar em Próximo.

## Ciclo de aprendizagem

1. Mel apresenta a tarefa.
2. Overlay mostra a interface.
3. Ponteiro guia demonstra.
4. Usuária faz com ajuda.
5. Usuária repete com menos ajuda.
6. Usuária responde um teste curto.
7. Usuária faz uma mini tarefa sem destaque.
8. App libera avanço.

## Tipos de fixação

### Reconhecimento

A usuária deve identificar uma parte da interface.

Exemplo

Clique na barra de endereço do navegador.

### Função

A usuária deve dizer para que serve algo.

Exemplo

Para que serve o botão Salvar?

### Sequência

A usuária deve ordenar passos.

Exemplo

Para criar pasta

1. Clicar com botão direito.
2. Escolher Novo.
3. Escolher Pasta.
4. Digitar nome.
5. Apertar Enter.

### Repetição

A usuária faz a mesma tarefa com outro exemplo.

Exemplo

Criou a pasta Receitas.

Agora crie a pasta Exames.

### Aplicação

A usuária faz uma tarefa completa.

Exemplo

Crie uma pasta, abra o Word, escreva uma frase e salve dentro dela.

## Bloqueio de avanço

Uma aula só libera a próxima se

1. Tarefa principal concluída.
2. Teste de fixação aprovado.
3. Tentativa repetida concluída.

## Quantidade de tentativas

Permitir tentativas ilimitadas.

Após 2 erros

Mel explica de outro jeito.

Após 3 erros

Minie mostra dica visual.

Após 4 erros

App oferece repetir demonstração.

Após 5 erros

App oferece chamar familiar ou recomeçar aula.

## Não gerar frustração

Nunca dizer que ela errou de forma dura.

Usar

Ainda não foi esse. Vamos olhar de novo.

Quase. A área certa fica um pouco mais acima.

Vamos repetir com o ponteiro guia.

## Teste prático obrigatório por módulo

### Janelas e duas telas

Mover uma janela para a outra tela.

Minimizar e recuperar.

Maximizar e restaurar.

### Explorador de Arquivos

Criar pasta.

Renomear.

Mover arquivo de treino.

Encontrar Downloads.

### Word

Digitar texto.

Selecionar texto.

Aumentar fonte.

Colocar negrito.

Salvar na pasta certa.

Abrir o arquivo salvo.

### PowerPoint

Criar apresentação.

Criar novo slide.

Inserir texto.

Inserir imagem de treino.

Apresentar em tela cheia.

Salvar.

### Internet

Abrir navegador.

Digitar site na barra certa.

Pesquisar.

Identificar anúncio.

Baixar arquivo de treino.

Encontrar arquivo baixado.

### ChatGPT

Abrir ChatGPT.

Iniciar conversa.

Escrever prompt simples.

Pedir passo a passo.

Pedir explicação mais simples.

Começar novo chat.

## Testes de fixação no ChatGPT

Exemplo 1

Qual é um bom pedido para fazer ao ChatGPT?

Resposta correta

Explique passo a passo como salvar um arquivo no Word.

Exemplo 2

O que não devo mandar no ChatGPT sem necessidade?

Resposta correta

Senhas e dados muito pessoais.

Exemplo 3

Quando uma resposta não ficou clara, o que posso pedir?

Resposta correta

Explique de um jeito mais simples.

## Revisão programada

Revisar depois de

1 dia.

3 dias.

7 dias.

15 dias.

## Método de revisão

Primeira revisão

Com dicas.

Segunda revisão

Com menos dicas.

Terceira revisão

Só com checklist.

Quarta revisão

Tarefa real completa.

## Nota de domínio

Cada aula gera pontuação interna

0

Não começou.

1

Assistiu.

2

Fez com ajuda.

3

Fez com pouca ajuda.

4

Fez sozinha.

5

Fez sozinha em revisão.

A próxima aula exige nota mínima 3 na aula anterior.

O módulo exige nota mínima 4 nas aulas principais para ser considerado fixado.

## Desbloqueio responsável

O familiar pode desbloquear uma etapa travada.

Esse modo deve ficar em Configurações avançadas.

Deve pedir confirmação.

Deve registrar no progresso.
